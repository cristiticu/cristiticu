### Projects

**[Helheim](https://github.com/cristiticu/helheim.backend)**
Serverless orchestrator that boots game servers on demand and shuts them down when idle.
FastAPI on Lambda, EC2 lifecycle through Boto3, DynamoDB single-table design. Its documentation
was generated by a multi-agent pipeline: a planner splits the repo into per-module tasks, workers
draft in parallel, a reviewer checks the drafts against the source, and a bot account opens the
pull request. Notes on what worked are in the README.

Live deployment at https://helheim.cristit.icu

**[Webeye](https://github.com/cristiticu-webeye)**
Synthetic monitoring platform that runs performance audits from 17 AWS regions. EventBridge into
SQS into a regional checker fleet, capturing DNS, TCP handshake, TLS negotiation, TTFB and Core
Web Vitals through a headless browser. Downtime has to reproduce across regions before it counts
as an outage. HAR archives land in S3.

**[Adapto CMS CLI](https://github.com/adaptocms/adapto-cms-cli)** (contributor)
Command line interface for a headless CMS, built so that LLM agents can drive it as well as
people can: JSON output, idempotent commands, generated command docs. Work project, public repo.
See also [create-adapto-app](https://www.npmjs.com/package/create-adapto-app) on npm, the
scaffolding CLI for the client SDK, with templates for Next.js, Astro and SvelteKit.

### Open source

Two performance issues reported against [`awslabs/aurora-dsql-connectors`](https://github.com/awslabs/aurora-dsql-connectors),
AWS's connector library for Aurora DSQL:

- [#644](https://github.com/awslabs/aurora-dsql-connectors/issues/644): the Python connector
  constructs a fresh `boto3.Session` and client for every pooled connection, which reloads the
  service models from disk and re-resolves the credential chain each time. Filed with benchmarks.
- [#645](https://github.com/awslabs/aurora-dsql-connectors/issues/645): the asyncpg and psycopg
  connectors call the synchronous token pipeline directly from the running event loop.
